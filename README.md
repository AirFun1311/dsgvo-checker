# DSGVO Compliance Checker

Automatisierter DSGVO-Check für Websites von kleinen und mittleren Unternehmen.

Das Tool analysiert eine Website und zeigt konkrete Datenschutz-Risiken inklusive klarer Handlungsempfehlungen.

Ziel: Abmahnrisiken erkennen und schnell beheben.
## Was das Tool prüft

- HTTPS-Verschlüsselung
- Datenschutzerklärung vorhanden
- Cookie-Banner Implementierung
- SSL-Zertifikat Gültigkeit

## Schnellstart
```bash
git clone https://github.com/AirFun1311/dsgvo-checker.git
cd dsgvo-checker
pip install -r requirements.txt
python dsgvo_scanner.py https://deine-website.de
```

## Ergebnis

Der Scanner gibt einen Risk-Score (0-100) und konkrete Handlungsempfehlungen aus.

## Professionelle DSGVO-Beratung

Dieses Tool ist die kostenlose Basisversion.  
Für vollständige DSGVO-Compliance-Prüfungen inkl. VVT (Art. 30), DSFA (Art. 35) und AVV-Checklisten (Art. 28) — **DSF Consulting, Nürnberg**.
